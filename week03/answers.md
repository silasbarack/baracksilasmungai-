# Week 3: Swing GUI and EDT
Activities 1–5 are covered by FirstWindow, SwingTour, EDTExample, and StudentPortal. SwingTour includes FlowLayout, BorderLayout, GridLayout and mixed layouts in tabbed examples. All top-level windows start on the EDT via SwingUtilities.invokeLater. EDTExample moves slow work to SwingWorker and updates the interface from done(). StudentPortal is intentionally a **static** GUI mockup, not a connected university service. The NetBeans drag-and-drop variant can be recreated by visually arranging the same widgets; generated .form metadata is not included.

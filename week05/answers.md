# Week 5
1. ContactListDemo: JList with a custom ListCellRenderer.
2. StudentTableDemo: editable model, sortable JTable, conditional renderer.
3. FileExplorerDemo: JTree nodes and JTabbedPane.
4. MiniEditor: JMenuBar, JToolBar, JFileChooser and JOptionPane, read/write text.
5. FileManager capstone: read-only folder navigation with refresh and parent navigation. File deletion and renaming are deliberately excluded to avoid destructive operations in an educational demo.
